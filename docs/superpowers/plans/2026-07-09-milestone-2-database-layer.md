# Milestone 2 Database Layer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the `prd.json` Milestone 2 database layer with SQLite, Drizzle ORM, migrations, a local database connection, and a sample query verification.

**Architecture:** Keep SQLite and Drizzle code in Node/Electron-side modules under `db/`, not in React renderer components. Use Drizzle Kit to generate SQL migrations from typed schema, then run migrations and verification scripts against `.local/stylecraft-dev.sqlite`.

**Tech Stack:** Electron, TypeScript, SQLite, `better-sqlite3`, Drizzle ORM, Drizzle Kit, `tsx`, Vitest.

## Global Constraints

- Build strict Milestone 2 only from `prd.json`.
- Do not implement product CRUD, renderer persistence, purchase workflows, sales workflows, reports, invoices, backup/restore, or UI changes in this milestone.
- Development SQLite file must be `.local/stylecraft-dev.sqlite`.
- `.local/` must be ignored because it contains local runtime data.
- Monetary values must be stored as integer cents.
- The renderer must not import database modules directly.
- Verification must prove migrations run, the database file is created, and a sample query works.
- The workspace is currently not a git repository; commit steps should be skipped unless git is initialized before execution.

```ts
import Database from "better-sqlite3";
import { drizzle, type BetterSQLite3Database } from "drizzle-orm/better-sqlite3";

import * as schema from "./schema";
import { ensureDatabaseDirectory, getDatabasePath } from "./paths";

export type StyleCraftDatabase = BetterSQLite3Database<typeof schema>;

export function createSqliteConnection(databasePath = getDatabasePath()) {
  const resolvedPath = ensureDatabaseDirectory(databasePath);
  const sqlite = new Database(resolvedPath);
  sqlite.pragma("foreign_keys = ON");
  return sqlite;
}

export function createDb(databasePath = getDatabasePath()) {
  const sqlite = createSqliteConnection(databasePath);
  const db = drizzle(sqlite, { schema });

  return { sqlite, db };
}
```

```ts
import { createDb } from "./client";
import { getDatabasePath } from "./paths";

export function runMigrations(databasePath = getDatabasePath()) {
  const { sqlite, db } = createDb(databasePath);

  try {
    migrate(db, { migrationsFolder: "drizzle" });
  } finally {
    sqlite.close();
  }
}
```

- [ ] **Step 4: Create sample query verifier**

Create `db/verify.ts`:

```ts
import { eq } from "drizzle-orm";

import { createDb } from "./client";
import { getDatabasePath } from "./paths";
import { settings } from "./schema";

export function runDatabaseVerification(databasePath = getDatabasePath()) {
  const { sqlite, db } = createDb(databasePath);

  try {
    const now = new Date();

    db.insert(settings)
      .values({ key: "db.verify", value: "ok", updatedAt: now })
      .onConflictDoUpdate({
        target: settings.key,
        set: { value: "ok", updatedAt: now },
      })
      .run();

    const row = db
      .select({ key: settings.key, value: settings.value })
      .from(settings)
      .where(eq(settings.key, "db.verify"))
      .get();

    if (!row) {
      throw new Error("Database verification failed: db.verify setting was not found");
    }

    return row;
  } finally {
    sqlite.close();
  }
}

if (import.meta.url === `file://${process.argv[1]?.replace(/\\/g, "/")}`) {
  const databasePath = getDatabasePath();
  const row = runDatabaseVerification(databasePath);
  console.log(`Sample query succeeded for ${databasePath}: ${row.key}=${row.value}`);
}
```
